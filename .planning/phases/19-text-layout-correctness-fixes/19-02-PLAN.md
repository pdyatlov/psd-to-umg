<objective>
Implement TXT-CAPS-01: when a Photoshop text layer has the character-panel "All Caps" toggle enabled, the generated UTextBlock must have TextTransformPolicy = ETextTransformPolicy::ToUpper (Photoshop renders the underlying string in uppercase without altering the layer's text content; UMG's TextTransformPolicy mirrors that exactly). Layers without All Caps keep the default ETextTransformPolicy::None.

Purpose: Designer intent for All Caps headlines (a very common UI pattern) is preserved through PSD → UMG without forcing the designer to manually uppercase the source text or re-toggle anything in UE. Uses native UMG locale-correct uppercasing — no hand-rolled string transform.

Output:
- One new field on FPsdTextRun (bAllCaps).
- One parser-side read of `style_run_font_caps(DominantRunIdx)` mirroring the existing FauxBold/FauxItalic pattern.
- One mapper-side `SetTextTransformPolicy` call gated on the new flag.
- Wave 0 RED specs (parser + pipeline) added BEFORE production code, plus a `text_caps` layer in Typography.psd. The implementation flips them GREEN.
- REQUIREMENTS.md TXT-CAPS-01 closed.

Scope-out: URichTextBlock (multi-run text). FRichTextLayerMapper does not get TextTransformPolicy in this plan — multi-run All Caps is a deferred gap (Pitfall 2 in 19-RESEARCH.md). FTextLayerMapper is gated to single-run text via `Spans.Num() <= 1`, so this plan covers the single-run path only.
</objective>

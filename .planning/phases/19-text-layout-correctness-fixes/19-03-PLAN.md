Per Phase 19 RESEARCH: PhotoshopAPI returns `Group->layers()` in top-to-bottom order; `ConvertLayerRecursive` appends children sequentially; `PopulateChildren` iterates 0..N calling `AddChild`. No spatial sort. No HBox/VBox heuristic resurrection. PSD layer stack order is designer intent — preserved as-is.

Option A — generator-side, scoped to non-canvas parents:

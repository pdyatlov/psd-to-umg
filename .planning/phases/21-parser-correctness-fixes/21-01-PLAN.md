<objective>
RTXT-01: Strip the trailing UTF-8 NUL sentinel that PhotoshopAPI's `text()` returns from BOTH the
single-run `Content` scalar path (PsdParser.cpp:204) and the multi-run `FullUtf8` path
(PsdParser.cpp:485) before passing to `Utf8ToFString`. Add a CJK / emoji fixture
(`RichTextCJK.psd`) and a `FPsdParserCJKSpec` automation spec block to make the fix empirically
verifiable.

Purpose: The `Utf8ToFString` helper uses `c_str()` which terminates at the first `\0`. PhotoshopAPI
embeds a trailing `\0` sentinel in the std::string returned by `Text->text()`, which truncates CJK
content at the null byte and produces garbled UMG output. CONTEXT.md D-03 locks the fix at the
call site (not inside `Utf8ToFString`). RESEARCH Pitfall 3 (and Open Question 2) confirms the
single-run scalar `Content` path is also affected and must be patched.

Output: PsdParser.cpp with sentinel-stripped Content + FullUtf8; new CJK spec block green; the
fixture PSD physically present in `Source/PSD2UMG/Tests/Fixtures/`.
</objective>

        for (const FPsdLayer& L : Layers)

            if (const FPsdLayer* R = FindLayerRecursive(L.Children, Pred)) return R;
        }
        return nullptr;

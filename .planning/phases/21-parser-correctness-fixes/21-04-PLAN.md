**UAT Subjects**
- Primary: `Source/PSD2UMG/Tests/Fixtures/Effects.psd` — ColorSpace=0 RGB color overlay and drop shadow.
- Optional secondary: any internal designer PSD on the user's host project that uses RGB color overlay or drop shadow effects.

**Verification Steps (per subject)**
1. Open the PSD in Photoshop. Note the Layer Style → Color Overlay color (HEX) and Drop Shadow color (HEX).
2. Take a Photoshop screenshot. Save as `21-04-photoshop-{subject}.png` next to this plan in the phase folder.
3. In Unreal Editor, drag the same PSD into the Content Browser to trigger import. Open the resulting WBP.
4. Take a UMG editor / preview screenshot. Save as `21-04-umg-{subject}.png` next to this plan.
5. Visually compare:
   - Color Overlay hue: does the UMG layer's tint match the Photoshop tint? (±5% per channel tolerance for the existing FromSRGBColor pipeline.)
   - Drop Shadow hue: does the UMG drop shadow tint match Photoshop's drop shadow tint?
   - Drop Shadow direction and offset: does the shadow drop in roughly the same screen direction with similar offset magnitude?
6. Record observations in `21-04-UAT-LOG.md` (template seeded by Claude in step 1 of <action>).

**Decision Rule**
- All channels match within ±5% AND drop direction/offset matches → set `status: pass`, write `## Verdict` = `PASS — RGB color overlay and drop shadow render correct hue`.
- Any channel diverges by >5% OR drop direction/offset is visibly wrong → set `status: fail`, write `## Verdict` = `FAIL — <one-sentence delta description>`, then add LFXC-02-FOLLOWUP row in REQUIREMENTS.md.
